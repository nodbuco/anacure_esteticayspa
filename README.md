# Sitio web · Ana Cure Estética & Spa

Sitio hecho con Next.js. Este README se completa en la última fase con la guía para los dueños
(cómo publicar un artículo, cómo cambiar textos y fotos, cómo activar la analítica).

## Correr en el computador

```bash
npm install
cp .env.example .env.local   # y pega el token de Easy!Appointments
npm run dev
```

Abre http://localhost:3000. La página interna http://localhost:3000/estilo muestra el sistema de diseño.

## Construir para producción

```bash
npm run build
npm start
```
